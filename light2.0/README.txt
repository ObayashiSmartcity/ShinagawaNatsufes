========================================================================
 ShopDrop / LINE ダッシュボード  一式
========================================================================

【同梱ファイル】
  index.html              … LINE ダッシュボード（ShopDropへの遷移ボタン付き）
  shopdrop.html           … ShopDrop ダッシュボード（新規）
  app.js                  … LINE 用ロジック
  app-shopdrop.js         … ShopDrop 用ロジック
  config.js               … LINE 用設定
  config-shopdrop.js      … ShopDrop 用設定
  styles.css              … 共通スタイル（両ページで使用）
  line_datamart.json      … LINE データ（日次差し替え可）
  shopdrop_datamart.json  … ShopDrop データ（日次差し替え可）

【別途必要（このZIPには未同梱）】
  04_obayashi_c.png       … 大林組ロゴ画像。上記ファイルと同じフォルダに置いてください。
                            （無くてもグラフは動作しますが、ロゴは表示されません）

------------------------------------------------------------------------
【表示方法】※ここが重要
------------------------------------------------------------------------
HTML をダブルクリック（file://）で開くと、ブラウザのセキュリティ制約で
JSON を読み込めず、グラフや切替が動作しません。必ず簡易サーバー経由で
開いてください。

  1. このフォルダを丸ごと任意の場所に解凍する
  2. フォルダ内でコマンドを実行:
        python -m http.server 8000
  3. ブラウザで以下を開く:
        http://localhost:8000/index.html      （LINE）
        http://localhost:8000/shopdrop.html    （ShopDrop）

------------------------------------------------------------------------
【ShopDrop ダッシュボードの構成】
------------------------------------------------------------------------
  ・上段タイル(3枚): 総登録数(グレー) / DROP登録数(青) / SHOP登録数(緑)
  ・登録者数グラフ : 全体 / DROP / SHOP をボタンで切替
  ・ユーザー属性   : 性別・年代を横並び、全体/DROP/SHOP を縦3段で比較
  ・カラー方針     : DROP=青系 / SHOP=緑系 / それ以外=グレー系

【データ差し替え】
  shopdrop_datamart.json を同名で上書きするだけで自動反映されます。
  （配列形式・{records:[]} 形式のどちらでも読み込み可能）
